# 等价类划分法

## 何时使用

- 功能点包含输入字段（金额、利率、期限、证件号、手机号等）且取值范围或格式规则明确；
- 输入组合爆炸，无法穷举时，用等价类压缩用例数量；
- 通常与[[boundary-value-analysis]]配合：等价类定「取哪个区间」，边界值定「区间里取哪个点」。

## 设计步骤

1. **识别输入条件**：从需求条目（FR-xx）中列出每个输入字段及其规则（类型、范围、长度、格式、必填性）。
2. **划分等价类**，逐字段建立等价类表：
   - **有效等价类**：符合规则的取值集合，编号 (1)(2)…；
   - **无效等价类**：违反规则的每一类错误，各占一个编号（超上限、低于下限、非法字符、空值、超长、格式错误——**每种违规单独成类**，因为一个用例只应暴露一种错误）。
3. **设计用例**：
   - 有效类尽量**合并覆盖**（一个用例覆盖多个字段的有效类）；
   - 无效类**逐类单独覆盖**（一个用例只覆盖一个无效类）；
   - 每个等价类至少被一个用例覆盖。
4. **标注追溯**：用例的「所属 FP-xx/FR-xx」填对应字段来源；设计依据写进用例说明。

## 银行示例

需求：贷款期限输入框，允许 1–360 个月，必填，整数。

| 等价类 | 类型 | 编号 |
|---|---|---|
| 1–360 之间整数 | 有效 | (1) |
| 0 / 负数 | 无效 | (2) |
| 361 / 10000 | 无效 | (3) |
| 非数字（"abc"、空格） | 无效 | (4) |
| 小数（12.5） | 无效 | (5) |
| 空输入 | 无效 | (6) |

→ 用例：TC-01 期限=240（覆盖(1)）；TC-02 期限=0（覆盖(2)）；TC-03 期限=361（覆盖(3)）……预期结果分别写「通过校验进入下一步」或「提示『期限须为 1–360 之间的整数』」。

## 与产物模板的衔接

- 等价类表可作为《测试用例说明书》的附录（「设计依据」），让评审者核验覆盖完整性；
- 每条 TC-xx 在说明栏标注覆盖的等价类编号，保证「每个等价类至少一个用例」可审计。
