# 情报报告模板

输出情报类报告时，严格使用以下 Markdown 结构。

## 结构

```
# {目标对象}情报简报
> 时间范围：{范围} ｜ 生成时间：{日期} ｜ 信息来源：公开检索

## 一、结论速览
- 3 条以内的一句话结论，每条不超过 40 字。

## 二、关键发现
按维度分小节（业务布局 / 产品功能 / 组织人事 / 营销动作 / 政策合规）。
每条发现写成：**{变化点}** — {说明}（[来源](链接)，{发布时间}）

## 三、影响与关注建议
| 事项 | 性质 | 理由 | 关注度 |

## 四、信息来源清单
编号列出全部链接及发布时间。

## 五、说明
本报告基于搜索引擎可见的公开信息整理，不含站点爬取或需登录数据；
仅作为信息汇总与线索整理，不作为经营决策依据。
```

做过合规校验时，在第五节前插入「合规提示」一节，列出风险点与处理结论。

## 排版纪律

- 每条结论后必须有来源标注；无来源的判断显式写「（推测）」。
- 没有内容的小节直接省略，不要写「暂无」凑结构。
- 不堆叠加粗大标题，层级只用 Markdown 标题符号表达。
- 全文中文，链接保留原文 URL 不做缩写。
